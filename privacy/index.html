隐私政策 / 个人信息保护说明

服务边界声明

本机构开展生命关怀公众信息导引与非医疗性志愿陪伴服务，不提供诊疗、床位与转介安排。志愿陪伴不属于医疗诊疗服务，不能替代专业医护、心理治疗或社会工作服务；涉及疾病诊断、疼痛及症状控制、治疗方案和用药问题，请咨询具备相应资质的医疗机构及专业人员。

本站不承诺服务效果；不公开服务对象可识别信息；未具备公开募捐资格前不开展公开募捐、不放置捐赠入口。

最近核验日期：〔最近核验日期〕

01

适用范围与不收集声明

本说明适用于〔机构法定全称〕运营的本站与全站页脚所列咨询、监督、公众号关键词渠道。

本站页面不收集、不存储个人信息：无注册、无登录、无在线表单、无站内检索日志、无留言与评论、无 Cookie 写入、无第三方统计与广告脚本。咨询、报名、更正均通过〔咨询电话〕〔咨询邮箱〕〔公众号名称〕办理，是否在沟通中提供联系信息由访客自行决定。

本站不收集老人可识别信息：正脸影像、姓名、床号、腕带、病历、门牌、病情与联系方式。不要求提供与本次事项无关的信息，不要求提供身份证明照片。

02

主动联系时的信息处理

  • 通过电话、邮箱或公众号主动联系时提供的信息，只用于回复本次咨询、安排报名、处理更正与下架请求，不用于其他用途，不向第三方提供。
  • 回复按公示渠道办理，不承诺具体天数，也不承诺服务效果。
  • 相关信息不在本网站留存，其处理依〔机构法定全称〕另行公示的制度执行。本站不写保存期限、不承诺具体天数。
03

更正与下架渠道

  • 查询、更正、删除相关信息，或要求下架某条公示内容，可通过〔咨询邮箱〕与页脚所列监督与投诉邮箱提出。
  • 提出时请说明事项与大致时间范围；不必提供老人信息，也不必提供与本次事项无关的材料。
  • 涉及已公示记录的更正，附记录日期与〔服务台账编号〕；处理流程见「信息公开 › 制度 03」。
04

对外发布的脱敏规则

对外发布的服务纪实、台账与图片，一律不出现服务对象可识别信息。重要信息不写进图片，以文本呈现，便于复制与读屏。公示类内容可直接截图转发，但不得据此反向识别个人。配图须为已授权素材〔可公开照片（已授权）〕；无授权图时改用纯 CSS 几何场景或留白。

05

外链与图片规则

  • 站内跳转均为静态相对路径；官方原文外链指向主管部门公开页面，新窗口打开并标注发布机构与访问日期。
  • 本站不引用外部字体、CDN、第三方图床与外链脚本；图片素材随站点一并托管。
